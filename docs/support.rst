Support
=======

If you run into a bug, have a feature request, or want to ask a usage
question, the fastest way to get help is to open an issue on GitHub:

- **Issue tracker**: https://github.com/RichieHakim/face-rhythm/issues

When filing a bug please include, at minimum:

1. The face-rhythm version (``python -c "import face_rhythm; print(face_rhythm.__version__)"``).
2. Your Python version and OS.
3. The full traceback.
4. A minimal code snippet or pipeline configuration that reproduces the
   issue.

For security-sensitive reports please contact the maintainer directly via
the email listed on the `GitHub profile
<https://github.com/RichieHakim>`__ rather than opening a public issue.
